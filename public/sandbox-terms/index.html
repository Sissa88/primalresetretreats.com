Sandbox checkout terms — draft

TESTING ONLY. These are not live booking terms. This page is provided solely to test the PayPal Sandbox checkout. No real money should be paid and no actual retreat place is reserved through a sandbox transaction.

What the test demonstrates

  • One guest chooses a private room or one bed in a shared room.
  • Test availability is limited to 5 private places and 10 shared places, 15 in total.
  • The private package price is $5,850 USD; the shared package price is $5,200 USD.
  • The OPENGATEHOSTEL promotion reduces the full package price by 30% before the deposit is calculated.
  • The checkout simulates collecting a 50% deposit and recording the other 50% as an outstanding balance due February 1, 2027. The remaining balance is not automatically charged.

Use test payment details only

Continue only when checkout explicitly displays “PAYPAL SANDBOX — TEST PAYMENTS ONLY.” Use a PayPal Sandbox buyer account. Do not use real payment details or send real money to test this flow.

Policies still to be agreed before real bookings

Final cancellation, refund, deposit, postponement, minimum-attendance, and late-booking policies have not been agreed or published here. This draft does not establish those policies or promise any refund outcome. Final terms must be reviewed, published, and accepted before live bookings open.

This draft page cannot be used to enable live checkout in the website’s booking configuration.
